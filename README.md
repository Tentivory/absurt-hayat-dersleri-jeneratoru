# Absürt Hayat Dersleri Jeneratörü

**Resmi, Ciddi, Bilimsel ve Tamamen Gereksiz Bir Proje**

Bu repository, insanlığın en büyük sorunlarından birine çözüm üretmek amacıyla kurulmuştur: Hayat derslerinin yeterince absürt olmaması.

## Özellikler

- **%100 Gerçek**: Kod çalışır. Deneyin. Pışman olmayın. Olun.
- **Bilimsel Temelli**: Rastgelelik prensibi üzerine inşa edilmiştir.
- **Ciddiyet Seviyesi**: 11/10
- **Patates İçeriği**: 0%
- **Anlam**: Yok. Var. Yok.

## Nasıl Kullanılır?

```bash
python3 absurt_dersler.py
```

Çıktı örneği:

```

...
```
